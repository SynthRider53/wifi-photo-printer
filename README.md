# Wi-Fi принтер фотографий (ESP32-C3 SuperMini + QR204)

Цель: печатать фото на термопринтере QR204 (58 мм, 384 точки, 203 dpi) с телефона,
Canon EOS RP (Wi-Fi) и Fujifilm XQ2 (режим instax). Прошивка — ESP-IDF v5.5.5.

## Этапы

1. **UART-связь с QR204, тестовая печать** — сделано.
2. **Wi-Fi-точка и веб-страница** — сделано (эта прошивка): дизеринг в браузере, печать с телефона/ноутбука.
3. **Печать прямо с Canon EOS RP по Wi-Fi (PictBridge)** — сделано.
4. **Печать прямо с Fujifilm XQ2 (эмуляция instax SHARE)** — сделано.
5. OLED + энкодер, карта SD.

## Печать с Fujifilm (этап 4)

1. На камере: «Настройка соединения» → «Настройка соединения принтера instax».
2. Имя принтера — SSID платы (`INSTAX-########`, показывает команда `wifi`), пароль — **1111**.
3. Меню просмотра → «Печать на принтере instax» → снимок → MENU/OK.

Камера шлёт JPEG 480×640 (около 100 КБ); плата декодирует его на лету и печатает 384×512 точек.

Плата изображает принтер instax SHARE: открытая сеть `INSTAX-########`, адрес 192.168.0.251,
TCP-сервер на порту 8080. Пароль «1111» — не ключ Wi-Fi, он едет в заголовке каждого пакета.
Что пришлось выяснить опытом (нигде не описано):

- **размер куска в ответе на «prepare image» должен быть 480 байт.** Настоящий SP-2 отвечает
  60000, но камера 2015 года такой кусок не принимает и обрывает связь сразу после объявления
  снимка. Подбирается на лету командой `ixchunk`;
- камера шлёт **JPEG** (формат 2 — протокол SP-1), а телефонное приложение — сырой RGB (формат 16);
  поддержаны оба;
- уровень заряда в ответах — 3 (как у настоящего принтера), 4 камера не принимает;
- команда 64 — «версия функции», ответ в том же виде, что у документированной 196:
  `[номер][значение]`; значение 0 камеру устраивает (команда `fnver`).

## Печать с Canon EOS RP (этап 3)

1. На камере: меню Wi-Fi → **«Печать на Wi-Fi принтере»**.
2. Подключиться к сети **PhotoPrinter** (пароль **photoprint**).
3. Выбрать принтер «PhotoPrinter», затем снимок, затем «Печать».

Камера сама находит плату и отдаёт снимок; ресайз, поворот по EXIF и дизеринг делает ESP.
Декодирование снимка 26 Мп занимает около 35 с, печать — ещё около 30 с.

Плата изображает принтер PictBridge over IP (CIPA DC-001/DC-005/DCG-006):
SSDP-объявление устройства `DPSPrinter:1`, описание по HTTP, SOAP `ConnectionRequest`,
затем плата сама подключается к камере по PTP-IP (TCP 15740) как инициатор и играет
роль DPS-хоста. Ключевой момент: после ответа на последний запрос возможностей
(`croppings`) принтер **обязан** сам прислать `notifyDeviceStatus`, иначе камера
на печати выдаёт «ошибка коммуникации».

## Печать с телефона (этап 2)

1. Подключиться к Wi-Fi **INSTAX-########** (имя показывает команда `wifi`), пароля нет.
2. Страница откроется сама — телефон покажет «вход в сеть». Если нет, открыть <http://192.168.0.251/>.
3. Выбрать, что печатать: **фото**, **текст** или **PDF**.
4. Подобрать настройки по предпросмотру и нажать «Печатать».

Текст рисуется в браузере, поэтому работает любой язык и любой шрифт телефона — плата
получает уже готовые точки. PDF открывается встроенной в прошивку библиотекой
[pdf.js](https://mozilla.github.io/pdf.js/) (лежит в образе в сжатом виде, отдаётся
страницей по `/pdf.mjs`), страница выбирается ползунком и дальше обрабатывается как фото.

Сеть открытая и с именем instax, потому что иначе камеры Fujifilm к ней не подключаются;
телефон и Canon это не мешает. Страница открывается сама за счёт `main/portal.c`:
все имена резолвятся в плату, любой неизвестный адрес редиректится на страницу.

Браузер сам уменьшает фото до 384 точек в ширину (альбомные поворачивает), делает дизеринг
и отправляет готовый битмап: ESP32-C3 без PSRAM картинки не декодирует.

Домашняя сеть (необязательно, точка доступа остаётся включённой): в консоли `wifi <ssid> <пароль>`,
адрес платы в домашней сети покажет `wifi`. `wifi clear` — забыть сеть.

### HTTP API

| Запрос | Что делает |
|---|---|
| `GET /` | страница |
| `GET /status` | JSON `{busy,done,total,copy,copies,width,maxrows,baud}` |
| `POST /print?h=<строк>&copies=<1..20>` | тело — сырой битмап `h × 48` байт, 1 бит на точку, MSB первым, 1 = чёрный; `h ≤ 2000`. Ответы: 200, 400 (размер), 503 (занят), 507 (нет памяти) |
| `POST /jpeg?copies=<1..20>` | тело — JPEG целиком; плата сама уменьшит, повернёт и напечатает (та же цепочка, что и с камеры) |
| `GET /desc.xml`, `GET /dpsconn.xml`, `POST /root/soap_folder` | UPnP/SOAP для PictBridge, не для ручного вызова |

Печатается одно задание за раз; пока идёт печать, новое получает 503.

## Подключение

| SuperMini | QR204 (TTL-разъём) | Примечание |
|---|---|---|
| GPIO21 (TX) | RXD | обязательно |
| GND | GND | обязательно, общая земля |
| GPIO20 (RX) | TXD | по желанию (команда `status`); уровень принтера может быть 5 В — через делитель 2:1 (например, 10 кОм + 20 кОм) |

Питание принтера — отдельное (аккумуляторы / блок), VH принтера к ESP **не** подключать.
Плату ESP питать по USB от компьютера. Распиновку разъёма сверить с шелкографией/даташитом
своей партии QR204: уровень должен быть именно TTL, а не RS232.

## Консоль

USB, COM-порт (сейчас COM14), 115200. Принтер работает только на 9600 бод (проверено `baudtest`).

| Команда | Что делает |
|---|---|
| `test` | печатает калибровочную полосу (линейка в мм, градиент, ступени серого, круг, линии, чёрная плашка) |
| `wifi` / `wifi <ssid> [пароль]` / `wifi clear` | адреса платы / подключиться к домашней сети / забыть её |
| `tail 75` | сколько точек выдвигать бумагу после картинки (ESC J 80 ≈ 9 мм) |
| `settle 1500` | пауза между растром и протяжкой, мс (короче — ESC J теряется) |
| `dither fs\|bayer` | растр для калибровочной полосы (в вебе выбирается на странице) |
| `ixchunk 480` | размер куска, который плата просит у камеры Fujifilm |
| `fnver 0` | ответ на запрос «версия функции» (команда instax 64) |
| `density 10` | плотность DC2 # 0..31 |
| `heat n1 n2 n3` | ESC 7: макс. точек, время нагрева, интервал |
| `speed 250` | максимум строк/с, которые ESP отдаёт принтеру |
| `baud 9600` | скорость UART до принтера (на лету, не сохраняется) |
| `baudtest` | печатает строку на 9600…115200, читаемая — рабочая скорость |
| `feed 48`, `init`, `status`, `feedtest` | протяжка в точках, ESC @, байты DLE EOT 1..4, замер способов протяжки |

Кнопка BOOT на плате тоже печатает калибровочную полосу.

## Сборка и прошивка

```powershell
.\tools\build.ps1 -Flash -Port COM14
```

Из Git Bash перед запуском убрать `MSYSTEM`, иначе ESP-IDF откажется активироваться:

```bash
powershell -NoProfile -Command "Remove-Item Env:MSYSTEM -ErrorAction SilentlyContinue; & .\tools\build.ps1 -Flash -Port COM14"
```

После смены `sdkconfig.defaults` (например, таблицы разделов) удалить `sdkconfig`.
Консоль — на встроенном USB Serial/JTAG (UART0 свободен). Открывая порт из скриптов,
ставить `dtr=False, rts=False`, иначе плата перезагрузится.

## Структура

- `main/printer.c` — драйвер ESC/POS: `GS v 0` растр полосами по 64 строки, темп под скорость печати, протяжка
- `main/printjob.c` — очередь печати: одно задание за раз, копии, хвост бумаги
- `main/wifi.c` — точка доступа + опциональная домашняя сеть (NVS)
- `main/webui.c`, `main/web/index.html` — HTTP-сервер и страница (ресайз и дизеринг в браузере)
- `main/pictbridge.c` — PictBridge over IP: SSDP, UPnP/SOAP, PTP-IP-инициатор, DPS-хост
- `main/instax.c` — эмуляция принтера instax SHARE для камер Fujifilm (TCP 8080)
- `main/portal.c` — «вход в сеть»: DNS на все имена и редирект на страницу
- `main/jpegprint.c` — потоковое декодирование JPEG (ROM TJpgDec) с ресайзом, дизерингом и поворотом по EXIF
- `main/dither.c` — потоковый Флойд–Стейнберг и Байер для калибровочной полосы
- `main/testpattern.c` — калибровочная картинка 384×340
- `main/shell.c` — консоль
- `main/board.h` — пины, скорость, имя сети
- `partitions.csv` — раздел приложения почти на всю флеш-память: в образе лежит pdf.js
